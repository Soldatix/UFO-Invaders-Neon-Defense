# UFO Invaders: Neon Defense

A free modern HTML5 arcade game by **Soldatix**, published on **Apps & Games**. The complete game engine, interface, audio, translations, and save system are contained in `index.html`; no framework or installation is required.

Live URL: <https://ufo-invaders.appsandgames.org/>  
Publisher: <https://appsandgames.org/>

## Hrvatski

### Pokretanje i igranje

Otvorite `index.html` u modernom internetskom pregledniku ili prenesite sadržaj repozitorija na statički hosting.

- Pomicanje: **strelice lijevo/desno** ili **A/D**.
- Pucanje: **razmaknica** ili **strelica gore**.
- Pauza: **P** ili **Esc**.
- Zvuk: **M**. Puni zaslon: **F**.
- Na telefonu i tabletu uključite dodirne kontrole na početnom zaslonu.
- Uništite neprijateljske formacije, zaštitite obrambenu liniju i skupljajte posebne moći.
- **Spremi i izađi** čuva trenutačnu misiju u pregledniku. **Izađi bez spremanja** briše spremljenu misiju.

## English

### Start and play

Open `index.html` in a modern web browser, or upload the repository contents to static hosting.

- Move: **Left/Right arrows** or **A/D**.
- Fire: **Spacebar** or **Up arrow**.
- Pause: **P** or **Esc**.
- Sound: **M**. Fullscreen: **F**.
- On phones and tablets, enable touch controls on the start screen.
- Destroy enemy formations, protect the defense line, and collect power-ups.
- **Save and Exit** stores the current mission in the browser. **Exit Without Save** removes the saved mission.

## Deployment

Repository name: `UFO-Invaders-Neon-Defense`

Cloudflare Pages settings:

- Framework preset: `None`
- Build command: `exit 0`
- Build output directory: `.`
- Root directory: leave empty (repository root)
- Production branch: `main`
- Custom domain: `ufo-invaders.appsandgames.org`

Every push to `main` will then trigger a new deployment automatically.

## Files

## Privacy and storage

The game uses browser local storage only for interface preferences, high score, and saved progress. It does not require an account or send game data to a server.
